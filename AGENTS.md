# AGENTS.md

## Project

React Native mobile app built with Expo and TypeScript.

## Goal

Help me build this project while learning. Do not over-automate.

## Learning Rules

- Explain important concepts before major code changes.
- Implement one feature at a time.
- Do not generate the whole app at once.
- Keep code readable and beginner-friendly.
- Avoid extra libraries unless clearly justified.
- Prefer simple solutions first.
- Do not add backend, auth, or AI features until the local MVP works.

## Workflow

Use this order:

1. Product spec
2. User stories
3. Data model
4. Mobile design
5. Screens / wireframes
6. Tasks
7. Implementation
8. Testing and refactor

## MVP Rule

The local MVP should work first before adding advanced features.

Local MVP means:

- Core screens work
- User can complete the main flow
- Data can be saved locally
- No backend required yet
- No login required yet
- No AI required yet

## Done Criteria

A task is done only when:

- The app runs without errors.
- The feature can be tested manually.
- Acceptance criteria are met.
- Code changes are explained clearly.
- I can explain the changed code myself.
